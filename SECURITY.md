# Security policy

## Supported version

Alleen de meest recente GitHub Release wordt actief onderhouden.

## Een kwetsbaarheid melden

Maak geen publieke issue aan voor nog niet opgeloste kwetsbaarheden. Gebruik GitHub **Security advisories → Report a vulnerability** in deze repository. Vermeld waar mogelijk:

- getroffen versie en Windows-build;
- minimale reproductiestappen;
- verwachte en waargenomen impact;
- relevante logs zonder echte mailheaders, persoonsgegevens, tokens of klantdata.

Open geen verdachte `.eml`- of `.msg`-bestanden in andere software om een melding te reproduceren. Deze tool leest alleen de voor analyse benodigde headerdata, maar een bestand blijft onbetrouwbare input.
